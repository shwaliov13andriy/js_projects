Опис коду
Я написав скрипт, який завантажує список шоу з API TVMaze, показує їх у вигляді карток на сторінці, дає змогу шукати за назвою і сортувати за назвою або рейтингом. Код працює в браузері без зовнішніх бібліотек і взаємодіє з елементами сторінки через їхні id.
Ось так працює мій код:
Підготовка елементів:  
Я отримую посилання на DOM-елементи: контейнер для карток, поле пошуку і дві кнопки сортування. Ці змінні потрібні, щоб показувати дані і реагувати на дії користувача.
Завантаження даних:  
Я викликаю fetchMovies(), яка робить fetch на https://api.tvmaze.com/shows. Якщо запит успішний, я зберігаю масив у змінну movies і відразу викликаю функцію відображення. Якщо щось пішло не так, я виводжу повідомлення про помилку в контейнер.
Відображення:  
Функція displayMovies(data) очищує контейнер і для кожного шоу формує HTML-картку з зображенням, назвою, жанрами і рейтингом. Я підставляю запасні значення, якщо якихось полів немає, щоб не ламати сторінку.
Фільтрація:  
Я підписався на подію input у полі пошуку. При кожному введенні беру текст, роблю його нижнім регістром і фільтрую початковий масив movies за назвою. Потім показую відфільтрований список.
Сортування:  
Для сортування я створюю копію масиву і сортую її:
за назвою через localeCompare;
за рейтингом у спадному порядку, підставляючи 0, якщо рейтинг відсутній. Після сортування показую результат.
Що важливо знати при використанні
Порядок дій: пошук завжди фільтрує по повному початковому масиву, а сортування застосовується до повного масиву, тому якщо спочатку відфільтрувати, а потім натиснути сортування, фільтр скидається.
Залежності: потрібні елементи з id movies, search, sortName, sortRating. Якщо їх немає, код може зламатися.
Сумісність: працює в сучасних браузерах з підтримкою fetch і ES6.
Прості покращення, які я б зробив
Дебаунс для пошуку щоб не перерендерювати при кожному символі.
Застосовувати фільтр і сортування разом щоб зберігати контекст користувача.
Показувати індикатор завантаження під час fetch.
Оптимізувати рендеринг через DocumentFragment або створення елементів замість багаторазового innerHTML +=.
Підмінне зображення якщо картинка відсутня або не завантажується.
